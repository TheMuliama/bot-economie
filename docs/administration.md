# Administration

Utilisez les commandes existantes pour produire (`m!produce`), autoriser un article (`m!shopallowitem`), le restocker (`m!shoprestock`), gérer la licence (`m!shoplicense`) et contrôler le coffre (`m!bankcheck`). Configurez le prix grossiste avec `m!shopsetprice`, puis le prix joueur avec `m!shopsetsaleprice`.

Suspendez une boutique avant une investigation. Consultez l'audit dashboard et les références d'achat avant toute correction manuelle. `RECOVERY_REQUIRED` exige une réconciliation : ne compensez pas deux fois une transaction.
