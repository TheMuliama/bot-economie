# Installation

Utilisez Python 3.12, créez un environnement virtuel, puis installez `requirements.txt`. Installez ce dossier comme cog Red et configurez les variables indiquées dans `.env.example`; ne versionnez jamais `.env`.

Le dashboard se lance avec la commande décrite dans [le guide dashboard](admin-dashboard.md). Configurez l'application OAuth Discord et ses URI de redirection avant exposition publique.
