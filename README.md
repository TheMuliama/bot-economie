# M Corp Bot

Bot Discord destiné à gérer les mécaniques M Corp du serveur Élite R&T.

## Architecture

DraftBot reste responsable de :

- l'économie ;
- la monnaie ;
- la boutique ;
- les paiements ;
- les logs de transactions.

M Corp Bot sera responsable de :

- l'inventaire ;
- l'utilisation des objets ;
- les effets temporaires ;
- les immunités ;
- les mécaniques M Corp.

## Stack

- Python 3
- discord.py
- SQLite
- Git / GitHub

## État du projet

Projet en cours d'initialisation.
